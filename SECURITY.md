# Security

This plugin connects to Droplinked's public hosted MCP endpoint and does not package credentials or a local server.

Do not place API keys, tokens, private merchant records, or personal data in plugin files or MCP arguments. Report suspected vulnerabilities or an exposed credential through Droplinked's official support channel at [droplinked.com](https://droplinked.com) and include only the minimum reproducible detail.

For current transport, authentication, and tool behavior, use the live discovery document documented in [README.md](./README.md). Treat the discovery document as authoritative when it changes.
